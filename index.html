1. HTML stands for Hypertext Markup Language.
  2. HTML provides structure to a website.
  3. The tag h1 is used for a heading, the tag p is used for paragraph, while the tag ol is used for ordered lists.
  4. The a tag is used for links, it requires a href though. It will look like this when done properly.
  5. CSS stands for Cascading Style Sheets.
  6. CSS adds style to a website.
  7. A CSS selector selects one element tag, such as h1, and adds styling to it using the { and } symbols with a tag in front of it. I don't know how to show an example.
  8. You would use the following code: body { background-color= (either color name or 6 letter hex) }.
  9. HTML and CSS work together by both adding styling and structure to a webpage, making it look nice.
  10. The link tag is used to actually apply the CSS properly.
